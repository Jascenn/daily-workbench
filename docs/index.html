Local-First Architecture

数据归你自己，每一条读写都有明确边界

工具只做你看得见、控得住的事：不上传云端、不静默写外部账号、断网也能打开。

严格只读边界

绝不替你发消息或改历史

  • 微信页只读本地 MCP 快照，绝不自动发送消息或修改会话状态
  • 语音转写与语义摘要优先走本机 Ollama / SenseVoice，不上传第三方
  • AI 判断一律标注“仅供参考”，原文证据一键核对
显式白名单回写

写回 Notion 必须人工确认

  • 仅对项目、客户、专注记录开放显式字段白名单回写
  • 本机服务默认仅监听 127.0.0.1:8787，支持 HttpOnly 会话 Cookie 与 CSP 安全头
  • 入口链接自动抹除地址栏 ?token=，不留本地明文令牌
零构建 · 离线兜底

没有 npm 黑盒，十年后照样能跑

  • 后端纯 Python 标准库，前端模块化由纯 Python 脚本拼装为单文件
  • 支持生成自包含离线页 workbench.local.html，断网双击即看
  • 内置访客脱敏模式，演示与截图与真实经营数据 100% 物理隔离

Quick Start

从 30 秒体验到完整接入你的日常工作流

不需要任何账号或 API Key 也能先跑起来；按需逐步接入 Notion、微信 MCP 与 Obsidian。

git clone https://github.com/Jascenn/daily-workbench.git
cd daily-workbench
python3 app.py
1. 零依赖启动：直接用系统自带的 Python 3 运行，无需安装 Node、Docker 或数据库。
2. 安全登录：打开终端输出的带 token 链接，服务端会自动签发 HttpOnly 会话 Cookie 并清除地址栏令牌。
3. 访客体验：未配置 Notion 时点击右上角「更多 → 访客模式」，即可完整体验 9 个页面的脱敏示例数据。
# 1. 一键并行同步 Notion / 资讯 / 自媒体 / 微信 / 雷达
bash scripts/sync-now.sh

# 2. 单独刷新知识星球 24h 日报 + 7 天周报
python3 scripts/sync/zsxq-daily-sync.py

# 3. 单独刷新微信只读批奏折快照
python3 scripts/sync/wechat-sync.py
Notion 接入：在 ~/.config/daily-workbench/ 放入 Notion Token 与数据库配置，即可拉取收支/项目/客户并开启白名单回写。
微信批奏折：配合本地只读微信 MCP + 可选 wechat-groups.json 白名单群配置，自动生成进展 Diff 与群选题。
Obsidian 写作与复盘：配置 Vault 路径后自动扫描章节字数、复盘笔记并生成固定 Vault 深链。
# 重新拼装单文件前端并执行 CSS 门禁检查
python3 scripts/build-workbench.py --check --lint-css

# 生成可双击离线打开的单文件快照
python3 scripts/sync/make-local.py

# 运行 800+ 前端逻辑测试
node scripts/tests/test-workbench-logic.mjs
离线兜底页：make-local.py 会把最新快照内嵌进 workbench.local.html，断网或停服时也能直接双击查看（自动备份轮转留 10 份）。
macOS 常驻：可配 launchd 让 app.py 随开机静默运行在 127.0.0.1:8787，并定时触发晨间同步。
运行环境：macOS / Linux · Python 3.10+ 前端构建：0 外部依赖（纯 Python 拼装） 可选增强：Ollama（qwen3:8b）/ Notion API / 微信 MCP / Obsidian

FAQ

常见问题

没有配置 Notion 或微信 MCP，能先体验吗？

完全可以。启动 python3 app.py 后切到「访客模式」，系统会在内存中注入一套完整的脱敏示例数据（覆盖收益、项目、客户、微信批奏折、资讯、写作与时间），不读也不写任何真实文件。

微信「批奏折」会帮我自动回复消息吗？

绝对不会。微信层从架构上就是严格只读的：只拉取本地只读快照与生成三口吻草稿复制到剪贴板，服务端不具备发微信能力（/api/wechat/action 保持 501 禁用），确保零社死风险。

为什么坚持零前端构建链（不用 React / Vite）？

个人工作台要陪你用很多年，而不是每隔半年修一次 node_modules 依赖冲突。当前采用 web/ 模块化源码 + 纯 Python 拼装与 CSS 重复门禁，既保持模块化可维护性，又做到单文件离线可双击打开。

我的经营与聊天数据存在哪里？会上传云端吗？

全部快照、缓存、状态与草稿均存在你本机目录与浏览器 localStorage 中，服务端默认仅监听 127.0.0.1，不向任何第三方遥测或云端上报。

支持深色模式和手机/窄屏查看吗？

支持。整套界面基于语义化设计令牌构建，浅色暖米纸与深色夜墨双主题一键切换，宽屏双列与手机窄屏单列自适应。
