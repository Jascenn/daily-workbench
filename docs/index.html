九个视角

每类事各有一个专注视角

总览

今天先做三件事、晨间速览（微信 / 雷达 / 星球）、经营体检、月度目标与当日时间线，一眼定优先级。

项目

看板 / 树状 / 日历三种视图，逾期与状态冲突直接标出，支持白名单回写 Notion。

客户

客户跟进、需求与收款节奏，跟进记录与 Notion 数据库联动。

微信 · 批奏折

本地 MCP 只读快照 + 增量进展对比，支持已阅/已处理自动重浮、白名单群选题与只读三口吻草稿复制。

时间

番茄钟专注、按项目工时与世界时钟，计时记录可单条回写。

资讯

自有订阅库健康检查、一键刷新订阅、选题雷达与博客级站内阅读排版。

写作

Obsidian 原生 Markdown 工作流：本地写作、章节进度与版本备份。

自媒体与星球

公众号、X、小红书与知识星球一站式运营，内置 24h 日报 / 7 天周报站内详版弹窗。

复盘

按周 / 月沉淀调试与经营复盘笔记，复用清晰阅读排版随时回查。

快速开始

三步跑起来

  1. 克隆仓库：git clone https://github.com/Jascenn/daily-workbench.git
  2. 启动本地服务：python3 app.py（仅依赖 Python 标准库，零外部构建链）
  3. 按启动日志打开带 token 的本地链接（自动下发 HttpOnly 会话 Cookie 并抹除 URL 令牌）

不配置 Notion 也能直接用：首次打开可进入访客模式，全部展示示例数据， 与真实账号、收益和自媒体数据完全隔离；也支持生成离线单文件 workbench.local.html 兜底查看。
